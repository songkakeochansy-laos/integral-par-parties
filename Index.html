1. Activité de découverte

Nous connaissons la formule de dérivation d'un produit :

(u × v)' = u' × v + u × v'

Cette formule permet de construire une nouvelle méthode de calcul des intégrales : l'intégration par parties.

Petite question

Quelle opération permet d'obtenir u' à partir de u ?

2. Point de cours

La formule fondamentale

∫ u(x)v'(x) dx = u(x)v(x) − ∫ u'(x)v(x) dx

Pour utiliser cette formule, il faut choisir :

  • u(x) : une fonction facile à dériver ;
  • v'(x) : une fonction facile à intégrer ;
  • u'(x) : la dérivée de u(x) ;
  • v(x) : une primitive de v'(x).

Exemple expliqué

Calculons :

∫ x eˣ dx

On pose :

  • u(x) = x
  • u'(x) = 1
  • v'(x) = eˣ
  • v(x) = eˣ

En appliquant la formule :

∫ x eˣ dx = xeˣ − ∫ eˣ dx
= xeˣ − eˣ + C
= (x − 1)eˣ + C

C est une constante réelle.

3. Exercices d'application

Exercice 1 : Niveau facile

Calculer une primitive de :

∫ x cos(x) dx
Voir un indice

Choisir u(x) = x et v'(x) = cos(x).

Voir la correction

u'(x) = 1 et v(x) = sin(x).

∫x cos(x)dx = x sin(x) + cos(x) + C.

Exercice 2 : Niveau moyen

Calculer une primitive de :

∫ x e²ˣ dx
Voir un indice

Choisir u(x) = x et v'(x) = e²ˣ.

Voir la correction

u'(x) = 1 et v(x) = e²ˣ/2.

∫xe²ˣdx = (x/2 − 1/4)e²ˣ + C.

Exercice 3 : Niveau avancé

Calculer :

∫₀¹ x eˣ dx
Voir un indice

Utiliser u(x) = x et v'(x) = eˣ.

Voir la correction

[xeˣ]₀¹ − ∫₀¹eˣdx = 1.
